# 混排球員數據 VolStats

排球比賽的**球員得失分紀錄 App**。每隊派一個人用手機記錄自己隊的得分、失誤，比賽中與賽後立即看到每位隊員的數據與分析圖表。

- 🎙 **語音 + 點按**：按住說「小新 殺球」，或點兩下（隊員 → 動作）就記一筆
- 📱 **網頁 App（PWA）**：不用上架，加到手機主畫面即可全螢幕使用，沒網路也打得開
- 👥 **多人分工**：同一隊多支手機一起記錄，資料自動合併
- 📊 **即時分析**：比分走勢、得失分來源、技術結構、輪轉、發球／接發、對手分析、局後報告

👉 開始使用：<https://shellyling.github.io/VolStats/>

## 功能

| 類別 | 內容 |
|---|---|
| 記錄 | 語音或點按記錄得分、失誤、表現；對方失誤／得分（可記背號與方式）；語音或打字記筆記；撤銷與修改 |
| 比分與局 | 依每一球自動計算比分與發球權；結束本局時確認比分並顯示局後報告 |
| 站位輪轉（選用） | 排先發、自動輪轉、換人、自由球員上下場；動作依站位縮減 |
| 數據 | 每位隊員的得分、失誤、淨值、進攻、效率、局勝率；歷史趨勢；比賽筆記 |
| 分析圖表 | 比分走勢、得失分來源、技術結構、對手、輪轉、發球／接發 |
| 匯出 | 球員統計 CSV、逐筆紀錄 CSV（含當下比分、發球方、輪轉、站位、筆記，適合丟給 AI 分析） |
| 使用問卷 | SUS 系統易用性量表，彙整全隊分數與意見，可比較各版本 |
| 隊伍管理 | 建立隊伍、隊員名單（背號、位置、綽號）、記錄碼／管理碼、試說語音辨識 |

### 動作分類

| 類別 | 動作 | 計分 |
|---|---|---|
| 得分 | 殺球、攔網、發球、吊球 | ＋1 |
| 失誤 | 發球失誤、攻擊失誤、被攔死、觸網、攔網失誤、接發失誤、接球失誤、違例 | －1 |
| 表現 | 接發未到位、舉球未到位、機會球沒到位、救球成功、發球好球、攻擊好球 | 不計分 |

動作清單可在試算表「動作」分頁調整（名稱、語音關鍵字、排序、啟用）。

## 快速上手

1. 打開網址 → 輸入隊名（例如「春日部防衛隊」）→ **建立隊伍**
2. 收好兩組代碼：**記錄碼**傳給隊友、**管理碼**自己保管
3. 到「隊伍」分頁新增隊員（例如 野原新之助・#5・砲位・綽號「小新」），每人按一次「🎙 試說」
4. 回到「紀錄」分頁按 ＋ 新增場次（對手例如「玫瑰班」），開始記錄

App 內右上角 **?** 有完整使用說明與 iPhone／Android 安裝教學。

> LINE 內建瀏覽器無法使用語音與安裝，請改用 Safari 或 Chrome 開啟。

## 架構

```
手機瀏覽器（index.html，PWA）
   │  POST（text/plain JSON，避開 CORS 預檢）
   ▼
Google Apps Script（Code.gs）── 權限檢查、寫入
   │
   ▼
Google 試算表「球員紀錄」── 資料庫
```

- **前端**：單一 `index.html`（HTML + CSS + JS，無框架），GitHub Pages 託管
- **後端**：Google Apps Script，綁定在「球員紀錄」試算表
- **離線**：紀錄先存在手機（localStorage），連線後自動補送；`sw.js` 快取畫面與資源

### 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | 整個 App（畫面、樣式、程式） |
| `sw.js` | Service Worker：離線快取 |
| `manifest.webmanifest` | PWA 設定（名稱、圖示、主題色） |
| `icons/` | App 圖示、favicon、logo |
| `vendor/pinyin-pro-3.28.0.min.js` | 中文讀音比對（語音認人名用），固定版本並以 integrity 驗證 |
| `Code.gs` | **不放在這個 repo**，貼在 Apps Script 編輯器（見下方部署） |

### 試算表分頁

隊伍、球員、動作、場次、紀錄、局比分、站位、筆記、問卷、統計

## 部署

### 後端（Apps Script）

1. 在試算表選 **擴充功能 → Apps Script**，貼上 `Code.gs`
2. 執行一次 `setup()`：建立／補齊所有分頁、預設動作與主辦代碼
3. **部署 → 新增部署 → 網頁應用程式**：執行身分「我」、存取權「所有人」
4. 把部署網址貼到 `index.html` 的 `API_URL`
5. 之後更新程式：**部署 → 管理部署 → 編輯 → 版本：新版本**（網址不變），新版有新分頁或新動作時再執行一次 `setup()`

### 前端（GitHub Pages）

1. 推送 `index.html`、`sw.js` 等檔案到 `main`
2. repo 設定 **Settings → Pages** 指向 `main` 分支根目錄

### 改版規則

每次修改前端都要：

- `sw.js` 的 `VERSION` 加一版（例如 `vs-v10` → `vs-v11`），舊快取才會被清掉
- `index.html` 的 `APP_VERSION`、`APP_DATE` 同步更新（顯示在說明、隊伍頁、頁尾）
- 若有改 `vendor/` 檔案，要一併更新 `index.html` 裡的 `integrity` 雜湊

### 示範模式

`API_URL` 留空，或在網址加 `?demo=1`，資料只存在這台裝置，不連後端。示範模式的主辦代碼為 `0000`。

## 權限與安全

- 每隊兩組 8 碼英數代碼：**記錄碼**（記錄、看數據、加綽號）與**管理碼**（另可改名單、刪場次、重設代碼）
- 主辦代碼（12 碼）可看全部隊伍，存在 Script Properties，**不要寫進 repo 或文件**
- 登入後使用 24 小時有效的簽章 token；重設代碼會讓舊 token 立即失效
- 同一裝置連續輸錯 5 次暫停 10 分鐘
- 內容安全政策（CSP）只允許自己網域與 Apps Script
- 語音原文預設不保存；可在試算表設定 30 天自動清除
